## Highlights

1.0.0-rc.2 is a **patch** candidate after [v1.0.0-rc.1](https://github.com/hilather/go-lab-netconf/blob/v1.0.0-rc.1/docs/releases/v1.0.0-rc.1.md). Toolchain, catalog, and MCP pin are unchanged. This tag folds two Unreleased fixes:

- `GET /v1/profiles` list items use camelCase `name`, matching detail GET and MCP `netconf_profiles_list` ([PR #4](https://github.com/hilather/go-lab-netconf/pull/4)).
- Default `spec.netconf.sharedProfileDatastore` is **`true`** so management/SPA/MCP profile datastores couple to the live data-plane store (Fixes #3; D28 revised). Explicit `false` remains a valid multi-tester opt-out ([PR #5](https://github.com/hilather/go-lab-netconf/pull/5)).

**Not in this tag:** NETCONF over TLS, RESTCONF TLS, RFC 8071 call-home (still v1.1). Integrator pin in mcp-integration-lab remains out of band.

## Added

- None. No new YAML fields, REST paths, MCP tools, or capability IDs beyond rc.1.

## Fixed

- `GET /v1/profiles` list items now use camelCase `name`, matching `GET /v1/profiles/{name}`, `GET /v1/users`, and MCP `netconf_profiles_list` ([PR #4](https://github.com/hilather/go-lab-netconf/pull/4)).
- Default `spec.netconf.sharedProfileDatastore` is now `true` so management/SPA/MCP profile datastores couple to the live data-plane store (Fixes #3; D28 revised to default true). Explicit `false` remains a valid opt-out for multi-tester isolation when combined with two users on two profiles ([PR #5](https://github.com/hilather/go-lab-netconf/pull/5)).

## Residual

- Not a production device. Not netopeer2. Not a manager. No YANG 1.1 compiler.
- No NETCONF over TLS. No call-home. No YANG-Push. No NMDA operational datastore. No confirmed-commit. No XPath filter.
- RESTCONF HTTP only. JSON only. Cleartext RESTCONF is a laboratory limitation.
- Notification `remoteAddr` is best-effort under Docker userland-proxy (NAT collision).
- Single replica. Memory store only. Reset and restart wipe the notification and audit rings.
- Integrator pin in mcp-integration-lab is **not** this tag (LAST, out of band).
- GHCR package may be private until a human marks it public. linux/arm64 not in this tag.
- Mira review is requested after the first UI landing.

Host residuals 10830 / 18303 / 18830. Appliance smoke uses `--netconf-listen=:1830 --restconf-listen=:8303` and `cap_drop: ALL`.
