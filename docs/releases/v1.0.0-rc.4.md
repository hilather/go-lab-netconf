# LabNETCONF 1.0.0-rc.4 Release Notes

Release date: 2026-10-26
Previous release: 1.0.0-rc.3
Application version: 1.0.0-rc.4

## Highlights

Toolchain-only release after 1.0.0-rc.3 ([#19](https://github.com/hilather/go-lab-netconf/pull/19)). Go toolchain 1.26.9 → 1.26.10. Go 1.26.9 lacks the crypto/x509 fix for GO-2026-6809. No behavior, API, MCP or configuration change.

## Added

- None.

## Changed

- Go toolchain pinned to go1.26.10: `go.mod` `toolchain`, CI and release `GO_VERSION`, Dockerfile `golang:1.26.10-alpine`.

## Residual

- Residuals from 1.0.0-rc.3 are unchanged. See [docs/known-limitations.md](../known-limitations.md).

## Deployment and operations

- The image build stage uses `golang:1.26.10-alpine`. Do not tag until required CI on the exact SHA is green.

## CI and release evidence

- Tag-gate requires that tag's own completed push run with every required CI job green. A pull-request run or a main-branch push of the same SHA does not satisfy it.
