## Highlights

LabNETCONF is a single-process laboratory appliance that answers **NETCONF 1.0/1.1 over SSH** (`:830` / host **10830**) and **RESTCONF JSON over HTTP** (`:8303` / host **18303**) from compiled YAML device profiles bound to the authenticated user. Candidate is the NETCONF edit overlay; commit publishes to running. RESTCONF writes running when candidate is clean (else `409 candidate_dirty`). Management (`/v1`, `/mcp`, operator SPA) is optional and defaults off.

This candidate freezes:

- License **Apache-2.0**
- Module **`github.com/hilather/go-lab-netconf`**
- Toolchain **Go 1.26** (`golang.org/x/crypto` **v0.56.0**)
- Image **`ghcr.io/hilather/labnetconf`** (scratch, UID 65532, no shell, no Node stage)
- MCP **2026-07-28 only**, tools **`netconf_*`**, resources **`labnetconf://`**
- Secrets as file refs; fail-closed YAML (`KnownFields`)
- Production notification inject is the in-process **ring**, not Nop
- Operator SPA at `GET /` when `spec.ui.enabled` is true

**Not in this tag:** NETCONF over TLS, RESTCONF TLS, RFC 8071 call-home. Schema keys `listeners.restconf.tls.enabled`, `listeners.callHome.enabled`, and `listeners.netconfTls.enabled` reject `true`. Those are v1.1.

## Added

- NETCONF 1.0 EOM and 1.1 chunked framing, SSH subsystem `netconf`, RESTCONF JSON on a dedicated listener.
- Per-user profiles (split-horizon), running/candidate/startup, commit/discard/lock, RFC 5277 in-process config-change ring and wait.
- Management REST `/v1` parity, bearer + cookie CSRF, MCP Streamable HTTP, operator SPA, slog JSON + hand-rolled OpenMetrics.
- Scratch image, compose smoke, integrator BOM under `examples/`.
- Tag-gate workflow (`.github/workflows/release.yml`) and `scripts/release-gate`.
- `golang.org/x/crypto` v0.56.0 (SSH adapter). `govulncheck` is clean.

## Residual

- Not a production device. Not netopeer2. Not a manager. No YANG 1.1 compiler.
- No NETCONF over TLS. No call-home. No YANG-Push. No NMDA operational datastore. No confirmed-commit. No XPath filter.
- RESTCONF HTTP only. JSON only. Cleartext RESTCONF is a laboratory limitation.
- Notification `remoteAddr` is best-effort under Docker userland-proxy (NAT collision).
- Single replica. Memory store only. Reset and restart wipe the notification and audit rings.
- Integrator pin in mcp-integration-lab is **not** this tag (LAST, out of band).
- GHCR package may be private until a human marks it public. linux/arm64 not in this tag.
- Mira review is requested after the first UI landing.

## Deployment and operations

Image `ghcr.io/hilather/labnetconf:v1.0.0-rc.1` and `sha-<7 hex>` after tag publish. No `:latest` on this prerelease. Scratch, UID 65532, HEALTHCHECK exec form, CMD `--management-listen=:8088`.
